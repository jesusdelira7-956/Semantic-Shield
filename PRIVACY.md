# Privacy Policy for Semantic Shield

**Effective Date:** November 8, 2026  
**Last Updated:** November 8, 2026

Semantic Shield ("the Extension") is an open-source, sovereign browser extension designed to protect your privacy and your local development environment.

### 1. Zero Data Collection
The Extension **does not collect, store, transmit, or sell** any personal data, browsing history, keystrokes, IP addresses, or device identifiers.

### 2. Local-Only Processing
All filtering operations—including network request rule matching via Chrome's `declarativeNetRequest` API, on-page cosmetic hiding, linguistic text analysis for synthetic content, and live logging—occur **strictly and exclusively inside your local device's browser memory**.

### 3. Local Storage Use
The Extension uses Chrome's `chrome.storage.local` API exclusively on your device to persist:
- Your user preferences (e.g. Master Shield toggle state, GenAI filtering toggles).
- Your custom user filter rules ("My Filters").
- Custom element-hiding signatures generated by the visual element picker.
- Temporary live debug logs (capped to 150 entries in local memory).

This data is stored locally on your machine and is never transmitted to any external server or third party.

### 4. Permissions & Usage
- `declarativeNetRequest`: Used to block ad, tracking, and local loopback network requests before they fire.
- `declarativeNetRequestFeedback`: Used exclusively to stream blocked request metadata to your personal on-screen debug logger.
- `storage`: Used to save your settings and filter lists locally on your machine.
- `sidePanel`: Used to display your power-user dashboard and live request stream in Chrome's side panel.
- `scripting` & `activeTab`: Used temporarily when you click "Pick & Heal Element" to let you select and suppress unwanted elements on the active webpage.
- `tabs`: Used to verify the current window context when opening the side panel.

### 5. Third-Party Services
The Extension does not use third-party analytics, remote tracking scripts, external CDNs, or telemetry servers.
